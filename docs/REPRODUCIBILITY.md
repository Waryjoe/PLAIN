# Reproducibility Status and Open Items

## What This Release Does

Archives selected source scripts, retains their original analysis logic and
numeric settings, replaces workstation-specific locations, removes literal
private case identifiers, and provides a data-free demonstration. Source hashes
are recorded before and after packaging. Originals were not edited.

Only package tests, source syntax checks, and the synthetic evaluation are
intended to be run during packaging. Full clinical/radiomics model fitting,
CT feature extraction, and patient-level manuscript reproduction are **not**
claimed as completed. See `RELEASE_CHECKS.json` for the actual checks performed.

## Scientific Provenance That Must Be Reconciled

1. **External subsets.** Historical Ningbo 133-case and Liaoning 355-case
   analyses involve post-hoc outcome/performance-informed selection. The
   Liaoning subset has 17 events and 338 non-events. Treat these as exploratory
   unless a separate, independently defined validation design can be supported.
   DeLong CIs here are conditional on selected cases and supplied predictions;
   they do not adjust for selection. Do not relabel these exclusions as missing
   imaging/clinical data without auditable evidence.
2. **Recent figure edits.** The author supplied revised AUC point values of
   0.931, 0.932 and 0.935 for 15, 20 and 30 features, respectively. The figure
   was edited in Illustrator, but corresponding new prediction outputs and
   recalculated uncertainty intervals have not been located/verified for this
   release. These numbers are not substituted into the analytical code.
3. **CV interpretation.** Historical feature ranking and hyperparameter search
   are not automatically nested in every OOF estimate. Review ranking scope,
   tuning reuse, repeated-OOF aggregation and meta-model cross-fitting before
   describing training estimates as unbiased or fully nested validation.
4. **Extraction branches.** The current manuscript-source matrix is v5:
   preprocessing on a 0.717 x 0.717 x 5.0 mm grid with training-derived global
   standardization, then no second resampling/normalization inside PyRadiomics.
   The separately locked v1 protocol uses a different extraction setup. Both
   YAMLs are unchanged; a v1 input cannot simply be processed with v5 settings.
   The v5 script itself calls this a sensitivity/GRAPE-inspired pipeline, not
   an exact reproduction of GRAPE preprocessing. This wording and the final
   manuscript need author reconciliation.
5. **Exceptional identifiers.** Literal case IDs were replaced with
   `PRIVATE_CASE_...` placeholders, including the preprocessing exception for
   a raw-coordinate reset. The private owner must map authorized anonymized
   IDs consistently before rerunning that branch. Do not silently drop it.
6. **Heatmap T4.** The original plotting script includes a sensitivity analysis
   around the extreme/constant Coarseness feature. The patient stays in the
   574-column heatmap; only that T4 value is excluded from the T4 calculation
   and marked in the display, leaving 573 values for that feature. Keep the
   sensitivity caption and distinguish it from full training-cohort model
   performance. Do not alter extreme values for appearance.
7. **Manually edited tables and panels.** This package does not guarantee that
   the newest Word table labels/units, four-cohort statistics, Adobe layouts,
   or all figure annotations are generated by the archived scripts.

## Packaging Transformations

- Quoted absolute paths are replaced with `plain_path(root, relative)`; the
  defaults point only to an empty ignored private workspace.
- Self-references resolve to packaged source files. Selected relative code-copy
  references are updated from `analysis/` to `scripts/`.
- A small local-only alias map replaces direct identifiers in source code.
  No real-to-alias map or private absolute source path is distributed.
- Formulas, model choices, seeds, numeric settings and source configuration
  bytes are not intentionally changed. Packaging is not new model validation.

## Publication Boundary

It is reasonable to share a clearly labeled code archive with these limitations.
It is not yet appropriate to call this an exact, fully reproducible final-paper
release. Resolve cohort definitions, result provenance, environment compatibility,
authors' permissions and licensing before making that claim.
