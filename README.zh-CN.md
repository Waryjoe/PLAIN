# PLAIN 论文代码整理包

本包整理了胃癌吻合口漏研究中临床建模、胃和肿瘤双 ROI 影像组学、融合建模、
性能评估及解释性作图使用的核心代码。原始文件均保留在原处。

**这是代码整理预发布版，不代表当前论文所有结果已经完整复现。**

## 已整理内容

- 23 个历史分析脚本，保留原文件名，便于回溯。
- v5 影像组学配置，以及单独标明的历史 v1 配置。
- 临床筛选、VIF、临床模型比较、LASSO 稳定性筛选、特征数比较、影像模型与融合。
- 临床和影像 SHAP、训练集热图、辽宁选定子集的 ROC/置信区间作图。
- 新增通用概率评估入口和模拟数据例子，输出 ROC、AUC/95%CI、校准和 DCA。
- 依赖清单、运行顺序、来源哈希、测试和上传前检查。

没有包含真实患者数据、病例名单、CT/mask、HE、患者级预测、模型权重和原始文稿。
本机绝对路径已改为可配置路径，代码中的少量真实病例标识已替换为占位符。
本机的来源对照和标识映射留在代码包之外，不要上传整个研究工作区。

## 使用方法

先看 [英文首页](README.md) 的模拟演示，再看 [运行说明](docs/RUNNING.md)。
所有命令在 `PLAIN-code` 根目录执行。默认工作目录 `private_workspace/`、运行输出
`outputs/` 均被 Git 忽略。真实分析需要机构授权的数据、原始工作表结构和完整环境。
